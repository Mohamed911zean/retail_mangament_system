# Documentation

This directory contains the project decisions and Phase 0 verification records.

## Structure

- `DECISIONS.md` — pinned versions, architectural decisions, and completed verification results.
- `ui.md` — how the renderer is built: tokens, component kit, i18n, navigation, and how to add a screen.
- `design_system/design_system.md` — the authoritative visual spec.
- `phase-0/` — step-by-step walking skeleton records.
- `phase-1/` through `phase-4/` — reserved for later implementation phases.

Phase 0 must pass before production features are built.
